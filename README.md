# terraform-infra-lab

A hands-on lab for learning and practicing infrastructure as code (IaC) using Terraform.  
This repository includes step-by-step examples for deploying and managing cloud infrastructure, primarily on AWS.

## Goals

- Understand core Terraform concepts and syntax
- Apply infrastructure as code practices using real cloud resources
- Build reusable, modular, and version-controlled infrastructure

## Contents

| Folder               | Description                         |
| -------------------- | ----------------------------------- |
| `00-hello-terraform` | First setup and local provider test |
| ...                  | More modules coming soon!           |

## Prerequisites

- [Terraform](https://developer.hashicorp.com/terraform) installed
- AWS account & IAM credentials (if using AWS)

## Usage

```bash
terraform init
terraform plan
terraform apply
```
